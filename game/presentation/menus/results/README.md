# menus/results/

Екран с резултати след завършен мач (docs/V1_GAME_DESIGN.md, раздел 5.3, 8.1).

Показва:
- крайното класиране
- статистика от мача
- спечеленото XP
- прогрес-лента към следващото отключване

Действия:
- Rematch      → същия MatchConfig → нов мач
- Следващо ниво → само при campaign мач
- Main Menu    → AppFlow.navigate_to_main_menu()

Имплементация: задача "Създаване на Results сцена".
