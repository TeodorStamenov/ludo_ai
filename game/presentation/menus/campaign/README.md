# menus/campaign/

Екран „Кампания" — списък/карта на нивата с прогрес
(docs/V1_GAME_DESIGN.md, раздел 5, 8.1).

Показва:
- jungle → desert прогресия
- завършени и налични нива
- XP прогрес и предстоящи отключвания

Играчът избира само животното си; темата, противниците и
level modifiers идват от `CampaignLevelDefinition`.

Произвежда същия `MatchConfig` като Match Setup.

Имплементация: задача "Създаване на Campaign сцена".
