# menus/main_menu/

Главното меню на Cosy Ludo (docs/V1_GAME_DESIGN.md, раздел 8.1).

Минималистично, cosy: бутони „Нова игра", „Кампания", „Настройки".
Стилов ориентир: Monument Valley / Alba — чисти, спокойни менюта.

Бутоните навигират чрез `AppFlow`, а не директно към сцените.

Имплементация: задача "Създаване на Main Menu сцена".
